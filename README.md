# Satwi Portfolio

Official developer portfolio and innovation dashboard for **Satwi** — AI Engineer, Embedded Systems Developer, and Full Stack Developer.

## 🚀 About

This repository contains the source code for Satwi's personal portfolio website, featuring:
- **AI & ML Engineering**: Multimodal models, prompt engineering, computer vision, and GenAI pipelines.
- **Embedded Systems & IoT**: ESP32, microcontrollers, custom sensor telemetry, and hardware-software integration.
- **Full Stack Development**: Modern web applications built with React 18, TypeScript, Tailwind CSS, and Framer Motion.
- **Interactive Demonstrations**: Embedded hardware telemetry simulations, skill proficiency maps, achievements roadmap, and direct contact options.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS v4, Motion (Framer Motion), Lucide Icons, Vite
- **Deployment & Hosting**: Vercel / Cloud Run / Static Web Hosting

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn or bun

### Installation
```bash
# Clone the repository
git clone https://github.com/satwi033/satwi-portfolio.git

# Navigate into project directory
cd satwi-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Building for Production
```bash
npm run build
```
